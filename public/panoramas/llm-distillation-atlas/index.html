ONE PREFIX / 同一个上下文

“天空通常是 ___ 的”

教师 logits = [4, 2, 1, 0]，学生 logits = [2, 2.5, 1, 0.5]。硬标签为“蓝色”。

教师分布 pT学生分布 pS

pᵢ = exp(zᵢ / τ) / Σⱼ exp(zⱼ / τ)。使用自然对数；τ² 是经典温度补偿，具体实现可不同。

这是固定 logits 的计算实验。 滑块只重算分布和损失，没有更新模型参数；损失数值随温度变化不代表能力提高。蒸馏温度与实际生成时的采样温度用途不同；逐 token KL 还要求词表与位置可比较。
