数据与口径

能追溯，比看起来完整更重要。

01 / 收录边界

收录窗口为 2025-10-03 至 2026-11-12（含首尾）。收录 14 家主要厂商的 60 个代表发布版本，侧重通用语言、编程和多模态理解；不穷尽所有厂商、参数尺寸、微调与快照，也未纳入专门的视频、生图、语音及向量模型。

02 / 价格可比性

优先使用厂商现行价目与模型文档，单位统一为每百万 Token，分输入与输出，保留原始币种。42 个版本有报价依据。既有条目的报价核验日期为 2026-10-03；本次新增或更新的条目按各自来源注明价格与核验日。页面不会自动更新。

03 / 成本如何计算

月成本 = 月请求数 ×（每次输入 Token × 输入单价 + 每次计费输出 Token × 输出单价）÷ 1,000,000。不同 Tokenizer、思考长度、质量、重试次数会影响实际花费；本页比较相同计费数量，不代表同等质量下的成本。

04 / 特殊费率

试算默认短上下文、非缓存、非 Batch、标准速度。DeepSeek 默认高峰，可切换非高峰；Gemini Flash 的限时价附有到期日；MiniMax M3 使用当前折后价；腾讯 HY4 的发布报价仅供查看，不进入现价试算。

05 / 时间与状态

优先采用官方首次发布日；GA 更新、产品与 API 分批发布、版本后缀日期均在详情说明。“官方发布”只证明历史发布事件，不保证旧版今天仍可调用。窗口之外的经典版本不参与统计。间隔按 UTC 日期计算，不外推下一次发布日期。

06 / 开放性与组织

“开放权重”不等于所有代码与训练数据开源，也不等于无条件商用。每个模型应按自己的许可证判断。未完成权重状态核验时明确标注；自部署仍有算力与运维成本。地区按研发厂商品牌归类，不代表数据驻留区域。
