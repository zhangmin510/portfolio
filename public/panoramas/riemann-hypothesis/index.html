命题与图解

先读懂这条线

把复数写作 s = σ + it。横坐标 σ 是实部，纵坐标 t 是虚部。如果 ζ(s) 恰好等于零，s 就是一个零点。负偶数 −2、−4、−6、… 给出一串平凡零点。黎曼问的是其余所有零点。

ζ(ρ) = 0，0 < Re(ρ) < 1
⇒　Re(ρ) = ½

零点的定义、对称性及表中近似值见 NIST 数学函数手册、LMFDB 零点表。

零点如何约束素数？

π(x) 数的是不超过 x 的素数，li(x) 是用密度 1/log t 积分得到的平滑估计。在显式公式里，每个零点 ρ = β + iγ 带来形如 xρ/ρ 的振荡，振幅随 xβ 增长。所有 β 都等于 ½，最终给出素数计数的误差界 π(x) − li(x) = O(√x log x)。NIST 公式 6.16.5

前人怎样逼近临界线

为什么可以排除边界上的零点？怎样从「线上有无穷多个」走到「至少占三分之二」？选择一项工作，沿着它的论证读下去。

1737欧拉乘积

从每个素数取一项，恰好得到每个整数

  1. 对一个素数 p，几何级数 1 + p−s + p−2s + ⋯ 等于 (1 − p−s)−1。每取一项，就选定了这个素数的指数。
  2. 把所有素数对应的级数相乘。比如 12 = 2² × 3，只能从 2 的级数取第二次幂、从 3 的级数取一次幂、从其余级数取 1。唯一分解保证每个正整数都出现恰好一次。用现代记法写作 ζ(s) = ∑n≥1 n−s = ∏p 素数 (1 − p−s)−1。
  3. 当 Re(s) > 1，级数绝对收敛，乘积的对数也收敛，故乘积非零。这样先排除了 Re(s) > 1 这个半平面内的零点。欧拉于 1737 年写下这项工作，论文在 1744 年发表。

1859黎曼的对称性

一条对称轴，带来一个更强的问题

  1. 定义 ζ 的级数只在 Re(s) > 1 绝对收敛。黎曼用解析延拓把 ζ 定义到其余区域（s = 1 为单极点），并引入今天记作 ξ 的整函数。乘上的因子消去了极点和负偶数处的平凡零点，留下的正是非平凡零点。 ξ(s) = ½s(s − 1)π−s/2Γ(s/2)ζ(s)。
  2. 函数方程 ξ(s) = ξ(1 − s)，再结合复共轭对称性，说明若 β + iγ 是零点，同一高度的 1 − β + iγ 也是零点。
  3. 想象高度 γ 处有两个点，实部分别是 0.3 和 0.7。它们已经满足这条镜面对称。黎曼猜想还要求每个点自己的实部都等于 0.5，必须另找理由把离线点对排除。

1896–1898排除边界零点

用一个完全平方，排除整条边界上的零点

1896 年，Hadamard 与 de la Vallée Poussin 分别证明 Re(s) = 1 上没有零点，进而得到素数定理 π(x) ∼ x/log x。Mertens 在 1898 年给出了下面这个短证法。

  1. 找一个总是非负的量。任取角度 θ，有 3 + 4 cos θ + cos 2θ = 2(1 + cos θ)² ≥ 0。
  2. 把每个素数代进去。固定 t ≠ 0、σ > 1，令 θ = kt log p。按欧拉乘积对数展开，把每项乘以正权重 p−kσ/k，对素数 p 和正整数 k 求和，再取指数，就有 ζ(σ)³ |ζ(σ + it)|⁴ |ζ(σ + 2it)| ≥ 1。
  3. 假设边界上有零点。若 ζ(1 + it) = 0，令 h = σ − 1 趋于 0。第一因子像 h−3 那样增大，第二因子至多为常数乘 h⁴，第三因子有界。乘积趋于 0，与上一步矛盾。t = 0 处则是已知的单极点。

1914Hardy 的变号法

如果再也不变号，两种面积必须相等

  1. 在临界线上，将 ζ(½ + it) 乘上一个随 t 变化、模为 1 的相位因子，得到实值连续函数 Z(t)。乘法保留全部零点，现在可以谈论正负。
  2. 假设从某个高度开始 Z(t) 始终同号。那么在任何足够高的区间 [T, 2T] 上，先取绝对值再积分，与先积分再取绝对值，答案相同。
  3. 一种现代证明估计这两个面积。∫|Z(t)| 至少为 cT，而振荡带来抵消，使 |∫Z(t)| 至多为 CT3/4（c、C 为正常数，均在 [T, 2T] 积分）。T 足够大时二者不可能相等，故在任意高处仍有变号。连续性保证临界线上有无穷多个零点。

1942–2020估算线上比例

无穷多个，在所有零点里占多少？

  1. 在高度 0 到 T 之间，把线上的零点数 N₀(T) 除以全部非平凡零点数 N(T)，按重数计。平方数也有无穷多个，却在整数里占比趋于零。Selberg 在 1942 年证明这里的比例下极限严格大于零。
  2. Levinson 用 ζ 及其导数构造辅助函数，把线上零点的下界转为对辅助函数零点的估计。再乘上一个精心选取的短狄利克雷多项式，称为 mollifier，用它缓和函数大小的起伏，使平方均值可以估计。
  3. Levinson（1974）把下界推过 1/3，Conrey（1989）推过 2/5。Pratt、Robles、Zaharescu 与 Zeindler 改进多项式和二阶矩的计算，使下界超过 5/12（2018 年预印，2020 年期刊卷）。这些分数是 T 趋于无穷时的保证。

1940年代–1974有限域的平行路线

换到有限域，可以把零点读作几何信息

  1. 取一条定义在有限域 𝔽q 上的光滑射影几何连通曲线。在每个扩域 𝔽qⁿ 中数它有多少点，把这些数编码成曲线自己的 ζ 函数。
  2. Weil 证明，这一函数的分子可写成 ∏(1 − αⱼu)，每个 |αⱼ| 都等于 √q。代入 u = q−s，零点满足 q−Re(s) = 1/√q，恰好给出 Re(s) = ½。
  3. Deligne 在 1974 年发表高维结果，对光滑射影簇第 i 阶上同调的 Frobenius 特征值，证明其复绝对值为 qi/2。这个证明依赖有限域的几何结构，经典 ζ(s) 还需要自己的论证。

2021严格计算验零

怎样确认计算没有漏掉一个零点？

  1. Platt 与 Trudgian 沿临界线计算实函数 Z(t)。每个数值都附有能容纳真值的区间。当两个采样点的区间严格异号时，就在两点之间锁定了至少一个零点。
  2. 单看变号可能漏掉间隔极近的两个零点，也可能略过偶重零点。作者用图灵法核对累计零点数，把临界线上找到的个数同整个临界带按重数计的总数对上。
  3. 2021 年发表的结果覆盖 0 < Im(s) ≤ 3 × 10¹²，这个范围内的每个非平凡零点都在线上，且都是单零点。3 × 10¹² 指虚部的高度；这项计算的保证在该高度截止。

2024–2026限制右侧零点数

若零点偏向右侧，它们能出现多少次？

  1. 选定 σ > ½，记 N(σ,T) 为高度 0 到 T、实部至少 σ 的非平凡零点数。离线零点如果存在，这个量可以衡量有多少落到了指定位置以右。
  2. Guth 与 Maynard 研究形如 ∑ aₙnit 的有限和能在多少个相隔开的 t 上同时取大值。零点探测方法把靠右的零点转为对这类大值的需求，限制大值出现的频率就限制了零点数。
  3. 他们得到密度上界 N(σ,T) ≤ T30(1−σ)/13 + o(1)。例如 σ = ¾ 时，指数为 15/26 + o(1)，这里 o(1) 随 T 增大趋于零。这给出了数量上限；上限仍容许有零点。预印本于 2024 年公开，期刊版发表于 2026 年 3 月。

2026.08至少三分之二

让线外的一对零点也留下可计数的贡献

  1. Alpöge 与 Furman 在 8 月预印本中报告了一个无条件下界。作者说明，这一论证由 Claude 找到，随后经两人核查。证明把 Weil 的厄米型限制到有限组测试函数，得到一块矩阵。这里的 Weil 型来自经典 ζ 函数的显式公式。
  2. 一个线上单零点贡献一个秩一的正项，镜像的离线点对贡献带有一正一负方向的块。把矩阵的秩、迹和平方范数联系起来，就能在保留离线点可能性的同时，反推出至少要有多少个线上单零点。
  3. 按重数计的全部非平凡零点中，至少三分之二同时满足「单零点」与「实部为 ½」。优化测试窗口给出的下界为 67.25%。这里统计的是渐近比例，剩余零点的位置要由其他论证确定。

Stepanov 的有限域方法给了新证明什么启发？

在有限域曲线上，Stepanov 构造一个辅助函数，让它在要数的点处多次消失。如果每个点至少贡献 m 重零，而零点总重数受函数次数约束，用总数除以 m 就得到点数上界。

Alpöge 在公告中写道，转向整数上的素数幂和时，难点是从哪里取得类似的重数。他与 Claude 转而研究连续的 θ 提升，让提升链的长度在不等式中承担放大倍数的作用。这说明了方法的来源；整数情形所需的格与估计则在新证明中另行建立。作者说明，第 1 页回看有限域路线

为什么一个上界就能排除零点？

取辅助模数 q₀ 为 18480 的正倍数，d 是模 q₀ 余 q₀/2 − 1 的素数。用 Λ(n) 表示素数幂权重，用 (n/d) 表示勒让德符号。对 n ≤ x 且 n ≡ 1 (mod q₀) 求和，每项取 Λ(n)(1 − (n/d))(1/n − 1/x)。减去 log(x)/φ(q₀) 与使余项趋于零的常数，便得到 Rd,q₀(x)。

对任意 ε > 0，充分大的 x 满足 Rd,q₀(x) ≤ x−½+ε。假设有零点 ρ 的实部大于 ½，就选 ½ < β < Re(ρ)，取 ε = β − ½。判据选取适当的 d，使相关扭曲函数在指定区域内无零点。此时余项变换在 ρ 处的留数由各特征的零点重数之和决定。Landau 型引理把这个留数压到零，各重数都是非负整数，于是 ρ 不可能是零点。

对模 N 的狄利克雷特征，证明可选 q₀ = 18480N。最后取 N = 1 就回到黎曼 ζ 函数；s = 1 要作为它的极点单独处理。留数与单侧判据尺度与参数
