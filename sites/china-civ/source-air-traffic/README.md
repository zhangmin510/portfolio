# 2024 年民航客运城市图层

原始资料由中国民用航空局于 2025 年 3 月 14 日公布。取附件中按全年旅客吞吐量排列的前 50 座境内民用运输机场，显示其中能匹配城镇名录的 49 座、46 个服务城市。原表对港澳台另行统计。[民航局公报](https://www.caac.gov.cn/XXGK/XXGK/TJSJ/202503/t20250314_226932.html) · [机场吞吐量排名原表](https://www.caac.gov.cn/XXGK/XXGK/TJSJ/202503/P020250314353470214193.xlsx)

旅客吞吐量按人次计，货邮吞吐量按吨计。数据表示年度进出港业务量。图上每个点是服务城市的地名位置。同一城市的入选机场合并，列表保留民航局所用的机场简称、名次及两项原数。北京、上海、成都各有两座入选机场。前 50 名中的西双版纳/嘎洒使用自治州名称，未匹配到同名城市，保留于 JSON 的 unmatched 字段。

同名匹配时，长沙限定湖南，海口限定海南。各城货邮分项以十进制定点相加。原始工作表列 A、B、C、G 分别为机场、客运名次、本期旅客吞吐量、本期货邮吞吐量。提取时验证逐机场旅客合计等于原表总数 1,459,517,710 人次。此次发布另以 openpyxl 对照原表验证 50 行旅客与货邮数字、名次和机场名，并复算 46 个城市合计。

在本目录运行 `python3 build_air_traffic.py` 即可利用保存的原表摘录重新生成 JSON。要从下载的原表重新提取，运行 `python3 build_air_traffic.py --xlsx /path/to/caac.xlsx`。生成器核对原件 SHA-256 后刷新摘录。
