# 台湾 2024 年谷类与分县市稻作

台湾农业部《113年糧食供需年報》的谷类生产明细以公吨列示，2024 年总计 **1,406,372 公吨**。其中米按糙米计 1,219,183 公吨，小麦 2,153 公吨、玉米 177,562 公吨、高粱 5,638 公吨、其他谷类 1,837 公吨。原表各项独立取整，分项之和与合计相差 1 吨。这个生产总量也与粮食平衡表公布的 1,406.4 千公吨（精确至百吨）一致。[生产量分项表，第 134–135 页](https://agrstat.moa.gov.tw/moasdweb/book/Book_File.ashx?chapter_id=1433_11_2) · [粮食平衡表，第 38–39 页](https://agrstat.moa.gov.tw/moasdweb/book/Book_File.ashx?chapter_id=1433_7_2)

《113年農業統計年報》在同一张稻米收获表中列出 1,542,942 公吨带壳稻谷与 1,219,183 公吨糙米。二者为同一批收成的不同加工口径。收获面积 240,284 公顷，稻谷平均单产 6,421 公斤/公顷。该表及杂粮分表逐一列出 22 个县市，稻谷有数字的为 18 个。澎湖县、基隆市、金门县及连江县的稻作列印作横杠，程序保存为缺值；其他作物按各自的单元格读取。[作物生产表，第 22–23、34–37 页](https://agrstat.moa.gov.tw/moasdweb/book/Book_File.ashx?chapter_id=1427_10_2)

大陆粮食统计涵盖谷物、豆类和指定薯类，谷物按原粮、豆类按干豆，甘薯和马铃薯按鲜重的五分之一折粮。台湾粮食平衡表把薯类、子仁及油籽另列，台湾作物年报的杂粮分类又含落花生与甘薯等。跨地区阅览时分别标注“大陆粮食总产量”和“台湾谷类生产量（米按糙米计）”。这些来源不足以仅凭两组汇总数可靠还原统一口径。[大陆粮食产量定义](https://www.stats.gov.cn/zs/tjws/zytjzbqs/lscl/202409/t20240909_1956326.html)

## 数据与复现

18 个县市的稻谷公布值逐项相加为 1,542,944 公吨，与年报合计相差 2 公吨。地图全台数值取年报合计行，县市数值取各自的行。

`grain.json` 的 `total.cerealsT` 取自生产量分项表。`balanceComponentsT` 保存同一张表的五项谷类分项。县市项保留官方五位代码（含前导零）、简繁体名称、稻谷与糙米产量、收获面积、单产和杂粮八项。吨数后缀为 `T`，公顷为 `Ha`，公斤/公顷为 `KgHa`。县市资料保留作物表中的县市范围与重量口径。各县市没有同表可比的“谷类生产总量”，因此该指标仅显示在全台层级。

`build_grain.py` 使用 Python 标准库解析三份农业部 ODS，读取表中印出的数值，校验版本 SHA-256、表头单位、年度、地区数量，并核对分项与汇总的四舍五入差。横杠为 `null`；印出的数字 0 保留为 0，可代表小于报告精度的已报告数值。

```sh
python3 source-taiwan/build_grain.py --cache-dir /tmp/china-civ-tw-grain
python3 source-taiwan/build_grain.py --cache-dir /tmp/china-civ-tw-grain --offline
```
