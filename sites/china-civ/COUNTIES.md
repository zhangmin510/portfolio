# 县域人口数据

县域浏览器使用董磊团队公开的县级人口普查资料。项目纳入中国大陆 31 个省级地区内 2,774 个有 2020 年常住人口和边界的统计单元。其中 2,666 个具有可比的 2010 年数据。研究者将部分发生边界调整的区县合并以比较两次普查，名称与多个区划代码均保留原貌。东莞等直辖乡镇的地级市按上游统计口径整体列出。

[研究论文，Lei Dong、Rui Du、Yu Liu，2022](https://arxiv.org/abs/2203.02130) · [数据集及采集与区划对齐说明](https://github.com/leiii/census/blob/0ba0f1efae092f4aa6569ef38e53b3bb4d2f0087/data/census/readme.md) · [国家统计局《中国人口普查分县资料—2020》](https://www.stats.gov.cn/zs/tjwh/tjkw/tjzl/202302/t20230220_1913738.html)

## 指标口径

| 指标 | 有值的单元数 | 口径 |
| --- | ---: | --- |
| 常住人口 | 2,774 | 2020 年，单位为人。2,668 条来自研究团队归集的人口普查公报面板；新疆的 106 条空值使用同一团队整理的第七次普查分县资料，以区划代码、区县名称及省份精确匹配。 |
| 十年人口变化 | 2,666 | `(2020 年人口 / 2010 年人口 − 1) × 100%`。以研究数据对齐后的边界计算。 |
| 0–14 岁占比 | 2,739 | 2020 年该年龄段在本单元人口中的比例。 |
| 65 岁及以上占比 | 2,738 | 2020 年该年龄段在本单元人口中的比例。 |
| 家庭户规模 | 2,631 | 2020 年平均每个家庭户的人数。 |
| 城镇人口占比 | 2,530 | 分县资料中的城镇人口除以同一单元的总人口。 |
| 平均受教育年限 | 2,530 | 2020 年分县资料中的平均受教育年限，单位为年。 |

补充指标仅在区划代码、名称、省份和 2020 年人口均与分县表一致时使用；缺项保留为 JSON 的 `null`。原表中金门县、西沙区、南沙区没有可匹配的 2020 年人口，港澳汇总行不属于大陆县级面板。覆盖范围与法定行政区数量会有差异。

边界与人口使用同一份研究面板。地图定位点取最大连通区域内的代表点，描边按经纬度简化至 0.012° 容差。多区合并时，定位点代表统计单元内的一个位置。

## 来源与复现

固定使用原仓库提交 `0ba0f1efae092f4aa6569ef38e53b3bb4d2f0087`。研究数据以 MIT 协议提供，署名 Lei Dong，2022。项目随人口数据一起提供[完整许可证](data/county-license.txt)。

在本目录执行以下命令可下载两张原表、许可证并重新生成浏览器的数据。指定 `--offline` 可使用已下载的原表离线重建。

```sh
uv run scripts/build_counties.py --cache-dir /tmp/china-civ-county-cache
uv run scripts/build_counties.py --cache-dir /tmp/china-civ-county-cache --offline
```

`data/counties.json` 包含所有单元的统计信息。`data/county-shapes.json` 保存与之对应的简化多边形环。通过 `id` 可将两份文件连接，包括用分号连接多个原始区划代码的合并单元。
