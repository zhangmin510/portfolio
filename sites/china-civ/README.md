# 中华舆图 · China Civ

[打开地图](https://zhangmin.name/china-civ/) · [设计参考 USACiv](https://karpathy.ai/usaciv/)

这张交互地图把真实的中国地形、城镇和统计资料绘制在兰伯特等角圆锥投影上。六角格中心在投影平面上间距 25 公里。可拖动缩放、点击地块与地名、切换数据透镜，或通过散点和表格定位到县域。分享链接保留选中的地点与地图设置，也可导出当前地图 PNG。

## 数据与口径

| 图层 | 资料与覆盖 |
| --- | --- |
| 海拔、地表、河湖 | NOAA ETOPO1、NASA MODIS 2024 与 Natural Earth。网格采用代表点采样，低于海平面的地形编码为零。[地形处理说明](TERRAIN.md) |
| 城镇和遗产 | GeoNames 的 1,559 个城镇与聚落点，及 UNESCO 的 61 项世界遗产。每项系列遗产取一个组成地标注。[数据版本与署名](source-places/README.md) |
| 省级透镜 | 27 项指标，覆盖人口、经济、农业、就业、民生、创新、能源、交通、教育与森林。主年份为 2024；森林覆盖率取 2014—2018 年森林资源清查。按有值地区五分位分组着色。[原表与重建](source-statistics/README.md) |
| 城市档案 | 36 座城市的 12 项经济社会指标及规则生成的城市特色；34 座城市的年度气温与降水。经济指标覆盖市辖县。GeoNames 人口有独立的统计口径。[城市标签规则](source-places/README.md) |
| 高校与民航 | 教育部直属高校按登记城市聚合。民航局 2024 年客运前 50 名中，49 座机场匹配至 46 个服务城市。按城市查看旅客人次和货邮吨数。[机场摘录与匹配](source-air-traffic/README.md) |
| 县域探索器 | 2020 年的 2,774 个县级统计单元，其中 2,666 个可比较 2010 与 2020 年。历史区划经研究数据协调。缺值显示为空缺。[统计口径](COUNTIES.md) |

能源、交通等统计透镜按省级地区着色。地图中的图标与地形纹理用于表达地理类别。国土窗口与边界概化见地形说明，图层中各指标分别列出年份、单位与原始来源。

## 本地运行

在本目录运行 `python3 -m http.server 8000`，再打开 [本地地图](http://localhost:8000/)。浏览器所需数据均已随源码保存，可在离线环境中浏览。网站部署到子路径时请保留文件之间的相对位置。

在 portfolio 根目录运行 `npm run check` 会测试主站、复制子站资产并完成整站构建。`node sites/china-civ/build.mjs` 可单独同步本图到开发服务器的静态目录。线上版本共用个人网站的 Cloudflare Worker。
