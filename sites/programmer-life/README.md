# 栈城日常 · Programmer Life

一个中文浏览器生活模拟游戏。你刚搬进梧桐里，要去字节花园开始新工作，也想为吃饭、朋友和自己的小工具留一点时间。

从第 1 天 08:00 开始，回家睡觉后可以开始下一天，或者打开「职业日历」处理职业节点。城市日常可按周继续，职业日历按事件推进到第三年毕业。初始设计见 [实现方案](docs/implementation-plan.md)。

## 本地运行

已构建的单文件版本为 `dist/play.html`，可直接用浏览器打开，无需启动服务。源码开发按下方步骤运行。

推荐 Node.js 22.13 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的 Local 地址，默认是 <http://127.0.0.1:5178>。运行目录为本项目目录 `programmer-life`。

```sh
npm test           # 规则引擎和本地存档测试
npm run build     # TypeScript 检查与生产构建，输出 dist/
npm run check     # 测试与构建
npm run preview   # 预览已构建的 dist/
```

应用是 React + TypeScript + Vite + Three.js 静态前端，无需服务端、账号或模型 API Key。`npm run build` 同时生成标准静态站点与内嵌脚本、样式的 `dist/play.html`。

视觉已改为对照 Lagos Life 的全屏低多边形三维场景、漂浮 HUD、头像需求提示和底部胶囊操作栏。鼠标拖动旋转、滚轮缩放；触屏可拖动和双指缩放，右侧也提供旋转、缩放、重置按钮。未启用 WebGL 时使用简化场景保留操作。

## 先玩通这一天

这是一条方便探索主要系统的路线，也可以按自己的节奏选择：

1. 创建角色：填写名字、选择背景、两种性格和本月愿望。
2. 点房间里的厨房/冰箱，展开物件行动菜单，确认吃一顿早餐。
3. 点底部「地图」，选择字节花园的建筑标记。可以开车、搭社区巴士或步行，镜头会跟随你沿路前往。公司 09:00 开工。
4. 做两轮「专注实现」，中间吃午饭。累计有效工作达到 240 分钟后，会收到产品经理的需求变更消息。
5. 回应消息：缩小范围、先接完整需求，或请林工协助。不同选择会影响时间、进度、质量、压力或关系。
6. 继续测试、聊天或工作到傍晚；精力不足时先「放空一会儿」。也可以去公园、咖啡馆、便利店或造物所。
7. 回家做饭、休息或推进个人项目。18:00 后可选择「睡个好觉」，查看回顾，再开始下一天或打开职业日历。

项目进度不必在首日达到 100%。这一天的目标是认识城市、体验工作与生活的取舍。省略工作也能结束首日，回顾会反映不同经历。

出行在动画结束后结算费用并推进游戏时间。可以跳过动画，或者在设置中减少动态效果。阅读消息、切换页面和离线均不会消耗需求。

## 日常和职业日历

- 从第 2 天起可以重复安排工作、午饭、午休、散步和个人项目。周三 17:00 后可约朋友散步，周五 16:00 下班，部分周六可自愿接班。普通工作和周末临时班的收入在当天睡觉后结算。
- 职业日历从首次上线开始，依次经历 618、应急故障处理、故障复盘、双十一、年终总结、绩效公布、年会和后两年的职责变化。复盘选择会影响下一次大促，绩效面谈中的回应会影响压力和后续沟通。
- 第三年可以完成交接并毕业，选择求职、独立开发或先休息。毕业后仍能继续过城市日常。

## 已实现的范围

- 两种背景、四种性格中选两项、三种愿望。
- 六个可到达地点：住处、公司、咖啡馆、便利店、公园、创客空间；住处和公司拥有可旋转缩放的三维房间，城市有道路、河流、桥和建筑。
- 开车、社区巴士和步行沿城市路线移动。未启用 WebGL 时使用二维路线动画。
- 吃饭、午休、实现、赶工、测试、AI 辅助、社交、散步、个人项目和睡眠。
- 需求与压力、现金支出、工程能力、职业信用、代码质量与技术债。
- 带分支的需求变更、职业事件、生活手记和每日回顾。
- 自动存档、有效备份恢复、JSON 导入导出、重新开始与减少动态效果。

AI 辅助是游戏规则选项，不调用真实模型。

## 存档与数据

每次行动后自动保存到当前浏览器的本地存储；重新打开相同地址即可继续。主存档无法读取时会尝试恢复上次有效备份，并显示提示。

- 在底部「手机」→「设置与账单」点击「导出」，下载 JSON 备份；回顾界面也可导出纪念存档。
- 「导入存档」先校验文件，再替换当前人生；原有效主档会保留为备份，写入失败不会先清空原存档。换设备或重新开始前，建议先导出。
- 「重新开始一段生活」确认后会清除本项目当前存档与备份，再回到角色创建。
- 清除浏览器网站数据、使用无痕窗口后关闭窗口、改变协议/域名/端口，可能导致当前地址无法继续原存档。导出文件可手动迁移。
- 看到「尚未保存」时，当前进度仍在该页面内；请重试保存或导出，离开页面可能丢失最近进度。
- 支持 Web Locks 的浏览器只允许一个标签页写入；其他标签页进入只读。关闭正在游玩的标签页，再刷新另一页即可继续。

进度不上传到服务端，也不提供跨设备自动同步。

## 代码结构

`src/domain/` 负责确定性规则，`src/content/` 保存地点和文案，`src/application/` 连接命令与存档，`src/persistence/` 负责校验及备份，`src/world/` 构建三维模型，`src/ui/WorldScene.tsx` 管理渲染与镜头，`src/styles/` 实现浮层与响应式布局。原 SVG 场景保留为 WebGL 不可用时的后备。
